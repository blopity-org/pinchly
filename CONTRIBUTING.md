# Contributing to Blopity Pinch

Thanks for your interest in contributing! Blopity Pinch is designed to be approachable for first-time makers and flexible enough for custom JavaScript tools.

## How to Contribute

- Fix bugs
- Improve UI/UX
- Add new modules
- Extend the JS terminal
- Improve documentation
- Create example apps

## Development Setup

1. Fork the repo
2. Clone your fork
3. Work inside the `/public` and `/core` directories
4. Submit a pull request

## Coding Guidelines

- Use clear, modular JavaScript
- Keep UI responsive
- Avoid unnecessary dependencies
- Document new features
