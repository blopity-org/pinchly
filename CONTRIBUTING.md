# Contributing to Pinchly

Thanks for your interest in contributing! Pinchly is designed to be modular, extensible, and friendly to both beginners and advanced developers.

## How to Contribute

- Fix bugs
- Improve UI/UX
- Add new modules
- Extend the JS terminal
- Improve documentation
- Create example apps

## Development Setup

1. Fork the repo
2. Clone your fork
3. Work inside the `/public` and `/core` directories
4. Submit a pull request

## Coding Guidelines

- Use clear, modular JavaScript
- Keep UI responsive
- Avoid unnecessary dependencies
- Document new features
